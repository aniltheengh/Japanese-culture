# Engineering office scenarios

[Home](../README.md) · [Workplace etiquette](07-workplace.md) · [Phrasebook](10-phrasebook.md)

These examples assume a team with a drawing register and designated reviewer. Use the actual project’s file controls, safety procedure and approval chain. All identifiers below are fictional.

## 1. Accept an assignment and confirm the deliverable

The task is “update the piping drawing.” Confirm the system and sheets, source revision, expected deliverables, recipient, deadline, reviewer and how to mark drafts. Ask who updates linked orthographic or isometric drawings and whether the support team needs a notice.

**Example:** 元図はRev. Cで、提出物は平面図とアイソメ図でよろしいですか。\
**Reading:** もとずはレブ・シーで、ていしゅつぶつはへいめんずとアイソメずでよろしいですか。\
**Romaji:** Motozu wa rebu shī de, teishutsubutsu wa heimenzu to aisomezu de yoroshii desu ka.\
**English:** Is Rev. C the reference drawing, and should I submit the plan and isometric drawings?

## 2. Report a delay with an option

> **Subject:** 配管図の進捗と納期のご相談\
> お疲れさまです。P-101の配管図は、機器図の最新版を待っているため、今日の提出が難しい見込みです。影響のない図面は今日16時までに提出できます。P-101は明日午前の提出でもよろしいでしょうか。

The message identifies the affected item, explains the blocker, offers a partial delivery and asks for a decision. Use the specific date in place of “tomorrow” when a message may be read later. Tell anyone whose schedule changes once the plan is confirmed.

## 3. Flag conflicting documents before modeling

The piping plan and current vendor drawing show different nozzle elevations. Record both document IDs and revisions, the affected line and the consequence. Mark the affected section as pending. Ask the responsible engineer which input governs and whether other drawings or equipment data need correction. Continue unaffected work if your lead agrees.

**Example:** 配管図と機器図でノズルの高さが異なります。どちらの図面を基準にすればよろしいですか。\
**English:** The nozzle elevation differs between the piping and equipment drawings. Which drawing should I use as the reference?

## 4. Handle a shared CAD or model problem

If the file shows a lock, stale reference or failed synchronization, pause edits to the affected file and tell the project coordinator or administrator. Capture the file name, location, time, what you were doing, and the exact error message. Ask who is editing and which copy is current. Follow the recovery procedure for your project. Record the decision before resuming so the team can avoid duplicate edits.

## 5. Disagree in a review with a concrete basis

> 現在のルートでは、バルブの操作スペースが不足する可能性があります。図面上の寸法は250 mmです。必要な寸法を確認したうえで、別ルートを検討してもよろしいでしょうか。

This says the current route may leave insufficient valve operating space, cites the drawing dimension and requests a check before exploring a new route. The example dimension is fictional. Check the actual access requirement, including equipment maintenance, before changing the model.

## 6. Respond to an error in an issued drawing

Notify the drawing owner and responsible lead promptly. Identify document number, revision, transmission date, affected recipients and possible fabrication impact. Ask the authorized owner to issue a hold or correction through document control. Update linked sheets and model data where applicable. Keep the superseded revision in the approved history.

**Example:** 発行済みの図面P-101 Rev. Bに寸法の誤りがあります。製作に影響する可能性があるため、至急確認をお願いします。\
**English:** Issued drawing P-101 Rev. B contains a dimensional error. Please check urgently because it could affect fabrication.

## 7. Raise a safety concern on site

Use the site’s immediate reporting procedure. State the location and hazard plainly, keep clear, and notify the responsible site lead. Follow the site’s stop-work procedure when applicable. A later email can document what was observed and who responded.

**Example:** 危険です。作業を止めてください。足場の固定を確認してください。\
**English:** This is dangerous. Please stop work and check that the scaffold is secured.
